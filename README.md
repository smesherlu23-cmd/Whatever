# Whatever

Веб-приложение для создания диаграмм и совместной работы в реальном времени. Разворачивается на собственном сервере.

Как устроено приложение и почему: [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск на сервере

Нужны Linux и Docker с плагином Compose.

```bash
POSTGRES_PASSWORD=сложный-пароль docker compose up -d --build
```

Приложение откроется на порту 8080 (меняется переменной `WHATEVER_PORT`). Миграции базы применяются при старте бэкенда. Проверка: `curl http://localhost:8080/api/health`.

Если приложение открывают по HTTPS (TLS на внешнем прокси), добавьте `WHATEVER_COOKIE_SECURE=true`: тогда браузер не отправит cookie сессии по открытому каналу.

### Первый администратор

Учётные записи создаёт администратор в разделе «Пользователи». Первого администратора создаёт команда на сервере, пароль она спросит дважды:

```bash
docker compose exec backend python -m app.cli create-admin admin --name "Иван Иванов"
```

Для скриптов пароль можно передать через стандартный ввод: `--password-stdin`.

## Разработка

| Часть | Папка | Стек |
| --- | --- | --- |
| Фронтенд | `frontend/` | TypeScript, React, Vite, Canvas 2D |
| Бэкенд | `backend/` | Python 3.12, FastAPI, SQLAlchemy (async), Alembic |
| Данные | — | PostgreSQL 16, Redis 7 |

Бэкенд:

```bash
cd backend
uv sync
uv run alembic upgrade head            # нужен PostgreSQL, адрес в WHATEVER_DATABASE_URL
uv run python -m app.cli create-admin admin --name "Разработчик"
uv run uvicorn app.main:app --reload
```

Фронтенд (запросы к `/api` и `/ws` проксируются на `localhost:8000`):

```bash
cd frontend
npm install
npm run dev
```

### Проверки перед pull request

Те же проверки запускает CI, и pull request не принимается, пока они не пройдут.

```bash
# бэкенд: линтер, форматирование, строгая проверка типов, тесты с покрытием ≥ 90%
cd backend
uv run ruff check . && uv run ruff format --check .
uv run mypy app tests alembic/env.py
uv run pytest --cov

# фронтенд: Prettier, ESLint, TypeScript, тесты с порогами покрытия
cd frontend
npm run check
npm run build
```

## Управление на холсте

| Действие | Как |
| --- | --- |
| Сдвинуть доску | колесо мыши, пробел + перетаскивание, средняя кнопка |
| Масштаб | Ctrl + колесо |
| Инструменты | V выделение, P рисование, R прямоугольник, U скруглённый прямоугольник, O эллипс, D ромб, Y треугольник, S стикер, A стрелка, T текст |
| Текст в фигуре | двойной щелчок или Enter; Esc завершает |
| Новый текст | двойной щелчок по пустому месту |
| Выделить несколько | рамкой или Shift + щелчок |
| Пропорции при изменении размера | Shift |
| Удалить | Delete или Backspace |
| Дублировать / выделить всё | Ctrl+D / Ctrl+A |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z или Ctrl+Y |

## Умное рисование

Инструмент «Рисование» (P) с включённым переключателем «Умное рисование» (так по умолчанию): каждый набросок сразу превращается в ровную фигуру — прямоугольник, эллипс (круг), ромб или треугольник. Прямая линия станет стрелкой, а если она начинается или заканчивается у фигуры, то привяжется к ней. Новая фигура встаёт по сетке, выравнивается по центру соседних фигур и берёт размер похожего соседа. Одно Ctrl+Z возвращает рукописный вариант.

Если переключатель выключить, инструмент рисует от руки и ничего не выравнивает. Распознавание работает в браузере, без запросов к серверу.

## Фигуры и стрелки

На панели инструментов есть прямоугольник, скруглённый прямоугольник, эллипс, ромб, треугольник, стикер и текст. Стикер — жёлтая заметка без рамки с тенью, в тёмной теме приглушённого цвета. Подсказка с названием и клавишей появляется при наведении на кнопку.

Стрелка, начатая или законченная на фигуре, привязывается к ней и следует за фигурой при перемещении. Переключатель «Прямая / Ломаная» рядом с инструментом стрелки задаёт вид новых стрелок и меняет выделенные. Ломаная стрелка выходит из фигуры и входит в другую сторонами, обращёнными друг к другу, и идёт под прямыми углами; если фигуры стоят почти на одной линии, она выпрямляется.

## Совместная работа

Доски перечислены на главной странице, у каждой свой адрес: чтобы позвать коллегу, отправьте ему ссылку. Все вошедшие пользователи видят все доски. Изменения участников видны сразу, у каждого свой цвет курсора и выделения, а подписан курсор именем из учётной записи.

Доска хранится и в браузере, поэтому открывается мгновенно и работает без связи с сервером. Изменения, сделанные без сети, отправятся автоматически после подключения, а состояние подключения видно в шапке.

## Учётные записи и оформление

- Вход по логину и паролю. Меню с именем справа в шапке: учётная запись (смена своего пароля), «Пользователи» для администраторов и выход.
- Администратор создаёт учётные записи, меняет имя и роль, задаёт новый пароль и блокирует. Заблокированный пользователь выходит на всех устройствах сразу, даже с открытой доской.
- Светлая и тёмная тема переключаются кнопкой в шапке. Пока тема не выбрана, берётся тема системы.
