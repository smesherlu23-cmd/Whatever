# Whatever

Веб-приложение для создания диаграмм и совместной работы в реальном времени. Разворачивается на собственном сервере.

## Запуск на сервере

Нужны Linux и Docker с плагином Compose.

```bash
POSTGRES_PASSWORD=сложный-пароль docker compose up -d --build
```

Приложение откроется на порту 8080 (меняется переменной `WHATEVER_PORT`). Миграции базы применяются при старте бэкенда. Проверка: `curl http://localhost:8080/api/health`.

## Разработка

| Часть | Папка | Стек |
| --- | --- | --- |
| Фронтенд | `frontend/` | TypeScript, React, Vite, Canvas 2D |
| Бэкенд | `backend/` | Python 3.12, FastAPI, SQLAlchemy (async), Alembic |
| Данные | — | PostgreSQL 16, Redis 7 |

Бэкенд:

```bash
cd backend
uv sync
uv run uvicorn app.main:app --reload   # нужен PostgreSQL, адрес в WHATEVER_DATABASE_URL
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

Фронтенд (запросы к `/api` и `/ws` проксируются на `localhost:8000`):

```bash
cd frontend
npm install
npm run dev
npm run test && npm run lint && npm run build
```

## Управление на холсте

| Действие | Как |
| --- | --- |
| Сдвинуть доску | колесо мыши, пробел + перетаскивание, средняя кнопка |
| Масштаб | Ctrl + колесо |
| Инструменты | V выделение, P умное рисование, R прямоугольник, O эллипс, D ромб, A стрелка, T текст |
| Текст в фигуре | двойной щелчок или Enter; Esc завершает |
| Новый текст | двойной щелчок по пустому месту |
| Выделить несколько | рамкой или Shift + щелчок |
| Пропорции при изменении размера | Shift |
| Удалить | Delete или Backspace |
| Дублировать / выделить всё | Ctrl+D / Ctrl+A |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z или Ctrl+Y |

## Умное рисование

Инструмент «Умное рисование» (P): рисуйте от руки, а в конце штриха задержите курсор примерно на полсекунды, как в Telegram. Набросок превратится в ровную фигуру: прямоугольник, эллипс (круг) или ромб. Прямая линия станет стрелкой, а если она начинается или заканчивается у фигуры, то привяжется к ней. Новая фигура встаёт по сетке, выравнивается по центру соседних фигур и берёт размер похожего соседа. Одно Ctrl+Z возвращает рукописный вариант.

Режим выбирается рядом с инструментом: «при задержке» (по умолчанию), «всегда» или «не выравнивать». Распознавание работает в браузере, без запросов к серверу.

Стрелка, начатая или законченная на фигуре, привязывается к ней и следует за фигурой при перемещении. Пока сервера синхронизации нет, доска сохраняется в браузере (IndexedDB).
