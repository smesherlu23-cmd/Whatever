# Безопасность

Краткая модель угроз Whatever: что защищаем, от кого, какими мерами и какие риски приняты
сознательно. Подробности мер — в [ARCHITECTURE.md](../ARCHITECTURE.md), настройки —
в [operations.md](operations.md).

## Что защищаем

| Актив | Где хранится | Чем опасна утечка или порча |
| --- | --- | --- |
| Содержимое досок, история версий, обсуждения | PostgreSQL (`postgres-data`) | схемы сетей и сервисов компании — ценные сведения для атакующего |
| Картинки и вложения досок | том `files-data` | то же, плюс файл может оказаться вредоносным для того, кто его откроет |
| Учётные записи и пароли | PostgreSQL, пароли — хешами Argon2id | вход под чужим именем |
| Сессии | cookie `HttpOnly` у пользователя, в базе — только SHA-256 токена | вход под чужим именем без пароля |
| Резервные копии | папка `backups/` на сервере, доступ только root | всё перечисленное выше сразу |

## От кого защищаем

1. **Посторонний в сети компании**, у которого нет учётной записи: подбирает пароли,
   ищет открытые адреса API, пытается нагрузить сервер.
2. **Пользователь с учётной записью**, который пытается увидеть или изменить чужие доски,
   получить права администратора или помешать коллегам.
3. **Неисправный или подменённый клиент**: присылает по WebSocket битые, огромные или
   слишком частые сообщения, чужие id в документе доски.
4. **Сторонний сайт**, открытый в браузере пользователя: пытается сделать запрос
   от его имени (CSRF) или встроить приложение в свою страницу.

Вне модели: администратор сервера и тот, у кого есть root или доступ к Docker на сервере.
Они видят всё по определению; от них защищает только порядок доступа к серверу в компании.

## Границы доверия

```
браузер ──HTTPS──▶ прокси компании (TLS) ──▶ nginx ──▶ бэкенд ──▶ PostgreSQL
                                             │                  └─▶ том files-data
                                             └─ единственный сервис, доступный снаружи
```

- Всё, что приходит из браузера, — данные, а не команды: тело запросов проверяет
  pydantic, документ доски и присутствие других участников проверяет клиент при чтении
  (`frontend/src/model/validate.ts`).
- Адрес пользователя бэкенд берёт только из заголовка, который выставил nginx; nginx верит
  `X-Forwarded-For` только от прокси из `WHATEVER_TRUSTED_PROXY`.
- База и бэкенд не опубликованы наружу: к ним можно обратиться только из сети compose.

## Меры

| Угроза | Мера |
| --- | --- |
| Подбор пароля | 5 неудач за 15 минут на пару «адрес + логин», 30 на адрес; nginx — не больше 10 попыток входа в минуту с адреса; одинаковый ответ и время для несуществующего логина |
| Кража сессии | cookie `HttpOnly`, `SameSite=Lax`, `Secure` за HTTPS; в базе только хеш токена; выход, блокировка и смена пароля закрывают все сессии и подключения к доскам сразу |
| Доступ к чужим доскам | права проверяются на сервере для каждого запроса и подключения WebSocket; зритель не может менять документ, его изменения отбрасываются сервером |
| CSRF и встраивание | изменяющие запросы и WebSocket — только с `Origin`, совпадающим с `Host`; `frame-ancestors 'none'` |
| XSS | строгая CSP (только свои скрипты и стили), React без `dangerouslySetInnerHTML`; загруженные файлы отдаются с `nosniff` и `CSP: sandbox`, SVG только скачивается |
| Порча доски чужим клиентом | битые элементы пропускаются при чтении; id файлов — только UUID |
| Перегрузка сервера | сообщение WebSocket не больше 4 МБ, присутствие не чаще 30 раз в секунду и не больше 64 КБ; отстающий клиент отключается при отставании больше 8 МБ; Argon2 в своём пуле из двух потоков |
| Заполнение диска | файл не больше `WHATEVER_MAX_UPLOAD_MB`, все файлы доски — не больше `WHATEVER_MAX_BOARD_FILES_MB`; журналы контейнеров ограничены по размеру |
| Потеря данных | ежедневная резервная копия базы и файлов, восстановление проверяется в CI на каждом изменении |
| Уязвимые зависимости | pip-audit и npm audit для зависимостей, Trivy для образов и CodeQL для кода в CI; Dependabot еженедельно; действия CI закреплены по SHA |
| Процесс с лишними правами | контейнеры бэкенда и nginx работают не от root; код в образе только для чтения |

## Принятые риски

- **Токены ссылок доступа хранятся в базе открыто.** Так ссылку можно показать снова
  в окне «Поделиться». Риск невелик: по ссылке всё равно нужно войти в систему,
  а ссылка выдаёт только права участника доски, которые владелец может отозвать.
- **Один процесс бэкенда.** Счётчики попыток входа и реестр подключений живут в памяти
  и сбрасываются при перезапуске. Перезапуск даёт атакующему новые 5 попыток на логин,
  но не чаще, чем перезапускают сервер.
- **Удалённые с доски файлы остаются на диске**, пока жива доска: они нужны версиям
  и отмене удаления. Место ограничено пределом на доску.
- **Зрители могут создавать обсуждения** — решение продукта. Частоту комментариев
  ограничивает только общий предел на размер и частоту сообщений.
- **Сервер не завершает TLS сам**: это делает прокси компании. Без него пароли идут
  по сети открытым текстом, поэтому установка без HTTPS — только для проверки.

## Как сообщить об уязвимости

Не открывайте публичный issue. Напишите владельцу репозитория через
[приватное сообщение об уязвимости](https://github.com/smesherlu23-cmd/Whatever/security/advisories/new)
на GitHub: что за уязвимость, как её воспроизвести и чем она грозит. Ответ — в течение
трёх рабочих дней.
