# Изменения

Все заметные изменения Whatever. Версии — по [SemVer](https://semver.org/lang/ru/):
мажорная меняется, когда обновление требует действий при установке, минорная — с новыми
возможностями, патч — с исправлениями. Как обновить сервер — в
[docs/operations.md](docs/operations.md#обновление).

## 0.2.0 — 2026-11-23

Исправления по ревью кода: скорость, устойчивость, эксплуатация и безопасность.

### Добавлено

- Ежедневные резервные копии базы и файлов (сервис `backup`), `make backup`
  и `make restore`; CI проверяет восстановление на каждом изменении.
- Показатели для Prometheus на `/api/metrics` (`WHATEVER_METRICS_TOKEN`) и id запроса
  в журнале и заголовке `X-Request-ID`.
- Нагрузочный тест синхронизации (`make load`) и бенчмарк документа (`npm run bench`).
- Предел места под файлы одной доски (`WHATEVER_MAX_BOARD_FILES_MB`, 1 ГБ).
- Готовые образы в GitHub Container Registry и архив образов для закрытого контура
  к каждому релизу; версия в `/api/health` и в меню пользователя.
- Проверки уязвимостей в CI (pip-audit, npm audit, Trivy, CodeQL);
  [docs/security.md](docs/security.md) — модель угроз.

### Изменено

- Перетаскивание: одна правка документа за кадр; снимок документа пересобирается только
  по изменённым элементам; курсоры участников рисуются на отдельном слое.
- Медленный участник больше не задерживает рассылку на доске; отстающий больше чем на
  8 МБ отключается.
- История доски сжимается и пока доска открыта; индекс `(board_id, id)` (миграция 0009).
- Защита от подбора пароля считает попытки и по адресу
  (`WHATEVER_LOGIN_MAX_FAILURES_PER_ADDRESS`); nginx ограничивает частоту входа.
- Ограничены размер сообщений WebSocket и частота присутствия.

## 0.1.0 — 2026-11-23

Первая версия: доски с умным рисованием, совместная работа в реальном времени и без сети,
учётные записи и права, страницы, стрелки, наборы фигур, картинки и вложения, экспорт PNG,
мини-карта, следование за участником, шаблоны, обсуждения с упоминаниями, история версий.
